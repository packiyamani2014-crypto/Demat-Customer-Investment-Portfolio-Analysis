# 📊 Demat Customer Investment & Portfolio Analysis

## 📌 Project Overview

This project presents an interactive Power BI dashboard designed to analyze Demat customer investments, investment product preferences, and portfolio performance. The dashboard helps users understand investment patterns through visualizations, KPI cards, and interactive filters.

## 🎯 Project Objectives

* Analyze customer investment patterns.
* Identify the most preferred investment products.
* Understand investment trends across age groups and genders.
* Analyze profit and loss performance.
* Track monthly investment trends.
* Identify the top 10 investment categories or records based on the selected metric.

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development and data visualization
* **DAX** – Calculations and measures
* **Power Query** – Data transformation
* **Microsoft Excel** – Dataset preparation
* **SQL** – Data querying and analysis
* **Python (Pandas & NumPy)** – Data cleaning and preprocessing

## 📈 Dashboard Features

* Key Performance Indicator (KPI) cards
* Customer investment analysis
* Investment product analysis
* Age group and gender analysis
* Monthly investment trends
* Profit and loss analysis
* Top 10 analysis
* Interactive slicers and filters

## 💡 Key Insights

The dashboard is designed to help users explore customer investment behavior, compare investment products, monitor portfolio performance, and understand profit and loss patterns.

## 📂 Project File

* `dashboard demat.pbix` – Power BI dashboard file

## 🚀 How to Use

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard visuals, KPI cards, and interactive slicers.
4. Apply filters to analyze different customer and investment categories.
